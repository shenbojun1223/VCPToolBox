## 生命周期模块
- 复用gravityOriginalStore，持有请求局部快照与原文仓。
- observe返回当前消息原对象，绝不以旧快照替换当前回执，不输出存根。
- 纯追加保留句柄；既有消息正文、元数据、附件、顺序变化或历史缩短时，保守失效全部旧句柄。
- restore自身也同步检查最新历史；不依赖调用方先observe。
- 拒绝不支持的结构、访问器、循环和超预算历史时失效原有句柄。
- response finish/close/error、AbortSignal以及run的finally负责释放；只移除自身监听。
- 不监听IncomingMessage普通close，避免将请求体结束误判为客户端断连。
- 实际本地HTTP断连测试确认：任务还在等待时，原文仓已经关闭；任务完成标志由任务自身finally更新，之后等待任务真实完成。
- 注册只针对显式索引的plain assistant字符串消息；不代表候选可被省略，也未施加完整语义保护策略。
- 无生产Handler挂接，无模型可调用恢复工具，无存根发送，无Token节省。
- 持有快照/深复制的真实负载成本尚未测量；预算约束不是硬实时保证。
- 关闭只释放模块持有引用，不等于取消外部工作或物理内存清零。
