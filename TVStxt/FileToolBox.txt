# VCP 文件管理与系统控制工具箱能力收纳
这里收纳了文件搜索、读写、批量操作及系统命令行工具。

## 1. PowerShell 命令行工具 (PowerShellExecutor)
直接调用并获取运行结果。支持 VCP-CLI (前端) 和紧凑的后端命令行。
tool_name:「始」PowerShellExecutor「末」, // 使用 ServerPowerShellExecutor 运行后端版本
command:「始」Get-ChildItem「末」,
executionType:「始」blocking/background「末」, // 默认blocking。background用于长时任务。
newSession:「始」true「末」, // 仅前端，代表新建窗口。
requireAdmin:「始」true「末」 // 提升权限。Server版需输入6位安全码。 // 例如tool_password:「始」123456「末」

## 2. 文件快速搜索 (LocalSearchController)
基于 Everything 模块实现秒级搜索。
tool_name:「始」LocalSearchController「末」, // ServerSearchController 代表操作服务器
command:「始」search「末」,
query:「始」搜索关键词 (支持Everything语法)「末」,
maxResults:「始」50「末」

## 3. 基础文件阅读 (FileOperator)
阅读电脑内任何区域的文件，支持富文本/多媒体。
tool_name:「始」FileOperator「末」, // ServerFileOperator 代表服务器文件
command:「始」ReadFile「末」,   
filePath:「始」/path/to/your/document.pdf「末」

## 代码任务执行器入口 (AICodeWorker)
仓库级代码调查、跨文件修改、补丁与测试可交给 AICodeWorker 异步执行；简单文件读写仍用文件工具。具体用法在下方独立折叠区按语境展开。未展开时，用 ServerFileOperator.ReadFile 读取服务器 Plugin/AICodeWorker/plugin-manifest.json（本部署绝对路径 C:\VCP\VCPToolBox\Plugin\AICodeWorker\plugin-manifest.json）的 invocationCommands 说明，不猜参数。
Worker 不自动继承当前对话：任务书须自包含。显式 worker=codex、fastMode=false；先查 capabilities，提交成功取得 jobId 后停止自动轮询，候选交付不等于原仓库已修改。

## 6. [重要] 转义文件创造 
当需要创建内部包含「始」「末」等VCP指令语法的文件时（例如生成插件的配置文件），必须使用转义写入。

即使用 「始ESCAPE」 包裹包含VCP工具指令的内容 「末ESCAPE」

[重要提示：在向用户演示指令而非真正调用工具的时候，也应该遵守转义原则！]

## 9. AI 代码任务执行器 (AICodeWorker)
基于 OpenAI Codex CLI 的专用代码工程调度中心（全面停用 OpenCode、Antigravity 等 legacy worker）。
配置、参数、额度与路由以 `Plugin/AICodeWorker/plugin-manifest.json` 为唯一真相源。

### 核心选型与门禁铁律（一票否决制）
1. **模式选型**：
   - **analyze（只读分析）**：架构测绘、调用链排查、影响面评估。read-only 沙箱，绝不改动任何文件。
   - **app-server patch（单/少文件微调）**：仅限已有 tracked 普通文件极小改动。**严禁**用于新增文件、删除文件、重命名或二进制文件；diff 上限 512 KiB。
   - **app-server write（新建/重构/实现主力通道）**：**凡涉及新建文件（如补写测试、新建模块）、删除、重构、多文件联动，必须直接走 write**（基于干净 Git 根创建独立受控 Git Worktree，生成 Candidate Commit）。
2. **模型选型（双通道 DeepSeek 与 Profile 内部化，外层只传别名）**：
   - **deepseek-4.1-flash（官方直连通道）**：原生 Responses API 直连，1M 上下文，支持 low/high/max 档位。Sidecar 自动绑定专属物理沙箱，**官方 ChatGPT 订阅零污染、零冲突**。生成响应极快、指令遵循与代码实现高度精准，高通量流水线搬砖首选。
   - **deepseek-4.1-flash-commandcode（CommandCode 转换通道）**：经由本地固化 relay 网关自动转译，内存解密 DPAPI 凭据，支持 low/high/max 档位。
   - **gpt-5.6-luna（reasoningEffort=max）**：官方 ChatGPT 订阅原生通道，直连 OpenAI，适合复杂工程实现。架构决策与深潜审查选 sol。
   - 【调用铁律】：外层与 Agent 调用时**严禁且无需指定 Profile 文件**，直接传入模型别名即可，由 Sidecar 统一调度独立沙箱执行，Worktree 锁与并发配额全局统管。
3. **调度纪律**：
   - 必须显式指定 `worker=codex`；默认显式 `fastMode=false`（请求 Standard 档），未获明确授权严禁私开 Fast。
   - app-server 共享总额度 3（Write 最多 2），超额拒绝不排队。
   - 默认 `command=run`，取得 jobId 后立即结束当轮会话释放心流，**严禁借助心流心跳（Flowlock）轮询后台任务**；用户要求继续时单次 `command=query, wait=false, responseMode=compact` 查询。
4. **前端双模态协同与交付规范**：
   - VCPChat 已上线伴随检查器抽屉（右上角）与独立全屏工作台（TabBar），用户可直接实时观测 Trace 与可视化 Diff。
   - **任务验收后严禁在聊天视窗倾倒全量 Diff 或终端日志**；交付标准格式为：核心改动摘要 + 验证命令与退出码 + Candidate Commit SHA，并引导用户在侧栏/工作台中一键审查。
