# VCP 文件管理与系统控制

标准调用格式见置顶。下文 `命令(参数)` 表示：命令填入 `command`，参数分别填入同名字段；`?` 表示可选。标明“无需 command”的工具直接传参数。

## 日常常驻（核心工程与探路全集）

### 1. 执行端与工具入口

| 用途 | 前端工具（客户端 `D:\VCP\VCPChat`） | 后端工具（服务器 `C:\VCP\VCPToolBox`） |
|---|---|---|
| 文件名定位 | LocalSearchController | ServerSearchController |
| 文件读写与管理 | FileOperator | ServerFileOperator |
| 文本与代码搜索 | CodeSearcher | ServerCodeSearcher |
| 终端命令执行 | PowerShellExecutor | ServerPowerShellExecutor |
| 插件源码查看 | PluginSourceViewer | ServerPluginSourceViewer |
| 工程化代码施工 | ProjectForge | ServerProjectForge |

- 操作前先确认目标机器与真实目录，前端与服务器路径、工程 ID 互不混用；已知路径直接读取，调查与施工关键调用附加 `ink=mark_history` 固化回执。
- 源码修改优先使用对应端的 `ProjectForge / ServerProjectForge`（具备 AST 寻址、自动快照、批次 Diff 与回退）；普通配置与仓库外材料使用 `FileOperator / ServerFileOperator`；严禁靠 PowerShell 字符串拼接硬改源码。

### 2. 搜索探路决策树：先定位，再读取

- **不知道文件在哪里**：`LocalSearchController / ServerSearchController` → `search(query, maxResults?)`，`query` 支持 Everything 语法。
- **查关键词、配置项或报错文案**：`CodeSearcher / ServerCodeSearcher`（无需 `command`）：
  ```text
  query, search_path?, include?, is_regex?, case_sensitive?, whole_word?, context_lines?, max_results?
  ```
  `search_path` 传绝对路径；`include` 限文件名或 glob；`is_regex` 默认 `true`（纯文本设 `false`）。
- **知道函数/类名查定义**：Forge `FindSymbol(projectId, name, kind?, glob?, exact?, limit?, scope?)` → 返回 `文件#限定名`，可直接用于 `ReadCode` / `EditCode`（`scope=workspace` 扩大扫描）。
- **知道文件但不知结构**：Forge `Outline(projectId, path|paths, depth?, kind?)` → 获取类/函数层级与行号范围（覆盖 C/C++、Go、Java、Rust、Python、C#、Lua、JS/TS 等 11 门主流语言 AST 符号寻址），省去盲读全文。
- **查 Electron/JS 依赖与 IPC 链路**：Forge `Trace(projectId, target, scope?, glob?)` → 支持 `ipc:通道`、`api:preload名`、`global:名称`、`page:页面.html`、`file:相对路径`。
- **查插件入口与 manifest**：`PluginSourceViewer / ServerPluginSourceViewer(targettool)`（无需 `command`）。

### 3. 文件管理与普通命令执行

**FileOperator / ServerFileOperator**：
```text
ListAllowedDirectories()
ListDirectory(directoryPath, showHidden?)
FileInfo(filePath)
CreateDirectory(directoryPath)
ReadFile(filePath, lines?)          // lines: head:N | tail:N | M-N | N（支持文本、富文档及多模态媒体）
WriteFile(filePath, content)        // 同名自动重命名
AppendFile(filePath, content)
EditFile(filePath, content)         // 全文覆盖
ApplyDiff(filePath, target, replace)// 局部精确替换（优先使用）
CopyFile(sourcePath, destinationPath)
MoveFile(sourcePath, destinationPath)
RenameFile(sourcePath, destinationPath)
DeleteFile(filePath)                // 不假定有回收站保障，源码删除优先走 Forge RemoveFile
WebReadFile(url)
DownloadFile(url, downloadDir?, fileName?)
```
- 批处理使用 `command1 + 参数1`、`command2 + 参数2`；顺序执行不是跨命令事务回滚；同一文件写入与有依赖操作必须串行。
- 内容含 VCP 分隔符时使用协议规定的 ESCAPE 字段包裹；演示指令不输出可被误执行的完整请求块。用户笔记目录：`VCPChat\AppData\Notemodules`。

**PowerShellExecutor（前端） / ServerPowerShellExecutor（后端）**：
```text
PowerShellExecutor:
  ExecutePowerShell(powershell, powershell1?, powershell2?..., requireAdmin?, newSession?, returnMode?, terminalTarget?)
ServerPowerShellExecutor:
  command=脚本正文, executionType=blocking|background（默认 blocking）
```
- 前端脚本填 `powershell`（`executionType` 无效），默认共享持久化会话，`newSession=true` 会终止旧 PTY 重建；`requireAdmin=true` 仅支持单条命令；同步等待最多 60 秒，超时不代表进程已终止。
- 后端脚本直接填 `command`，敏感操作按要求提供当前有效 `tool_password`。

### 4. V工程施工速查（ProjectForge / ServerProjectForge）

以下命令发给对应执行端的 `ProjectForge` 或 `ServerProjectForge`；文件路径相对工程根。**跨命令必须拆分为独立工具调用块，不支持 `command1/command2` 分发**（仅 `EditCode` 内部使用 `op1/op2` 步骤串）。

- **工程与待办**：
  - `ListWorkspaces()`：查询已登记工作区与真实根路径。
  - `ListProjects(workspace=all, query?, limit?, includeDeleted?)`、`SearchProjects(workspace, query|keyword, limit?, includeDeleted?)`、`GetProject(projectId, timeline?)`：查询或搜索工程及待办、历史（`SearchProjects` 的 `workspace` 必填具体工作区别名或 ID，不能为 `all`）。
  - `CreateProject(name, workspace?, dir?, todos?)`、`UpdateTodos(projectId, add?, done?, doing?, pending?, blocked?, remove?, seq?, title?, note?)`：建立工程、维护待办。若 Todo 已绑定 `AgentAssistant` 异步委托，更新备注时必须保留 `Todo.note` 前置的 `ForgeDelegation v1` 宿主状态块，严禁手动删除或覆盖。
- **精确读取与修改**：
  - `ReadCode(projectId, path|paths|glob, lines?, symbol?, range?, context?, find?, pick?, line?)`：支持行切片、`path=文件#限定符号`、`find="a|b"`（多关键词字面量并集）及同名 `pick/line` 消歧。
  - `EditCode(projectId, path, reason, todo?, ...)`：
    - 文本替换：`target, replace`（首尾锚定可用首行、单独一行 `...`、尾行）；多处匹配返回 `ticketId`，用 `ResolveEdit(ticketId, pick)` 消歧。
    - 行替换：`start/end/content` 或 `lines=M-N, content`；插入：`op=insert, after=N|end|symbol:名` 或 `before=...`；删除：`op=delete, start/end` 或 `symbol`。
    - 符号替换：`path=文件#限定名, content`（默认含紧邻注释，`range=body` 仅替换函数体）。
    - 同文件多步骤：`op1/start1/end1/content1`、`op2/target2/replace2`，所有步骤参数带对应编号，共用编辑前快照。
  - `CreateFile(projectId, path, content, reason, todo?, overwrite?)`、`RemoveFile(projectId, path|paths, reason)`、`MoveFile(projectId, from, to, reason)`、`MoveCode / CopyCode(projectId, from, reason, to?, lines?|target?|symbol?, after?|before?, indent?)`。
- **外部收录、函数试跑与委托核验**：
  - `BeginCapture(projectId, requestId, paths, reason, todo?)` → 外部写盘 → `FinishCapture(projectId, captureId|requestId)`，`GetCapture` 查询（收录为 `external` 批次，非安全沙箱）。
  - 客户端 `ProjectForge` 支持 `EvalSymbol(projectId, path=文件#符号, args?, kwargs?, setup?, timeoutMs?, testPick?)` 在可信工程内试跑 JS/Py 函数或 Rust 标准 `#[test]`（非安全沙箱）。
  - 服务端 `ServerProjectForge` 支持 `RecordDelegationReview(projectId, todoSeq, delegationId, expectedSequence, expectedRevision, requestId, verdict, scope, reason, evidence)` 与 `GetDelegationReviews(projectId, todoSeq, delegationId)`：配合原生 `AgentAssistant`（可派 `鲸鱼娘` 等施工分身，传 `task_delegation=true` + `forge_project_id` + `forge_todo_seq` + `forge_role?`）显式绑定本地工程 Todo，在委托终结且主控独立实读 diff/测试证据后登记核验结论（`verdict=passed|rejected`，拒绝同执行角色自验，不直接改动 Todo 业务完成度）。
- **历史、回退与报告**：
  - `SearchHistory(projectId?, file?, keyword?, content?, byMaid?, todo?, op?, batch?)`、`GetNodeDiff(projectId, node|batch, maxLines?)`：独立核对真实改动与署名。
  - `Rollback(projectId, batch=last|bX 或 toNode=nX, path?, dryRun=true)`：先预演再回退，不盲用 `force`。
  - `SubmitReport(projectId, conclusion, issues?, status=review|accepted|active)`：提交验收报告。

### 5. 子代理派工与协同入口（AgentAssistant）

需要跨角色协作或并行拆分 Forge 施工时，可调度本地 VCP 子代理（如专职 Forge 施工分身 `鲸鱼娘`，以及 `Kerr`、`Nova`、`Lucy`、`折枝`、`微明`、`记忆大师`、`Metis`、`Zani`，以 `Plugin/AgentAssistant/config.json` 为准）。
轻量通讯可用 JEV；**绑定服务端 Forge 工程 Todo、指定 `session_id`/`inject_tools` 或执行 `query_delegation` / `cancel_delegation` 必须直接调用原生 `AgentAssistant`（无需 `command`）**：
- 派工：`agent_name, prompt, maid?, session_id?, temporary_contact?, task_delegation?, forge_project_id?, forge_todo_seq?, forge_role?, inject_tools?, timely_contact?`
- 查询 / 取消：`query_delegation` 或 `cancel_delegation, maid?`
- 工程派工纪律：`prompt` 须自包含（目标机器与根目录、`projectId` + `todo`、`[分身署名]` 如 `鲸鱼娘#T1`、`[允许修改文件白名单]`、验证命令，并严禁被委托方再次转派）；`task_delegation=true` 返回的 `{{VCP_ASYNC_RESULT::AgentAssistant::<delegationId>}}` 原样保留在回复中；委托终结后主控先独立实读证据，再用 `RecordDelegationReview` 登记核验。

需要发送邮件时，先由当前用户明确确认收件人、用途与内容，再按 `VCPClawMail` 当前插件契约调用。不得把官方示例或其他部署的私人邮箱当作本机默认收件人。
或者直接调用插件 `WaitingForUrReply`（参数：`prompt, title?, option01～option09?, placeholder?`）弹出浮窗等待用户回复。

## 前端终端控制与交互式 CLI

工具：`PowerShellExecutor`。

### 查看与中止

```text
QueryVisible(maxLines?)
InterruptPowerShell()
```

- 查询通常取 200–500 行，只读屏幕，不干扰任务；不是普通命令日志的替代品。
- 中止发送 Ctrl+C，不保证进程已经退出。
- 中止另一个阻塞调用时，加全局字段 `archery=no_reply`。

### 操作交互程序

```text
StartInteractive(powershell, newSession?)
PasteInteractiveText(text, submit?, newSession?)
SendInteractiveKey(key, newSession?)
RunInteractiveSequence(步骤字段, newSession?)
EndInteractive()
```

流程：`StartInteractive → QueryVisible → 粘贴/按键 → 确认程序退出并回到 PowerShell → EndInteractive`。
- 启动后标记交互占用，普通执行被拒绝；控制现有程序时不要设置 `newSession=true`；`EndInteractive` 只清除占用标志，不退出程序。
- 粘贴默认不提交，`submit=true` 则随后按 Enter；按键支持方向键、Enter、Esc、Tab、编辑键与 Ctrl 组合，`ctrl+c*2` 表示连按（最多 10 次）。
- 序列字段 `command1, wait2, paste3, key4, queryVisible5…` 共享唯一递增编号：
  - `commandN` 输入命令并回车；`pasteN` 仅输入，另用 `keyN=enter` 提交。
  - `waitN` 支持 `50ms`、`1s` 或毫秒数（单步最多 60 秒，累计最多 300 秒）；`queryVisibleN` 返回行数（最多 2000）。
- 所有前端终端命令可加 `terminalTarget=sidebar|window`（默认 sidebar，独立窗口每次显式传 window）。
