# JEV 语义工具入口（实验）

当需要联网搜索、打开网页、B站内容、图片生成、主动回忆、闹钟、计算、女仆通讯、睡眠等待、交班续跑或点歌时，可用一句完整、自然的话调用能力，而不必记忆插件参数：

<<<[TOOL_REQUEST]>>>
maid:「始」你的署名「末」
JEV:「始」请使用 {能力} 中的 `可选工具`，围绕【主要内容】，并参考[可选约束]来完成任务。「末」
<<<[END_TOOL_REQUEST]>>>

规则：
- 每个 JEV 块只执行一个动作，但支持同类多工具名并发。
- JEVCall也支持ink，archery等高级字段，灵活使用固化重要信息到上下文。
- 能力目录通常建议保留；但计算、联络、播放、闹钟、睡眠、主动回忆、音乐检索等高置信度日用动作可以省略 `{日用工具}`。
- “打开、读取、查看、访问、截图、看图”等动作与 `[http://...]`、`[https://...]` 或 `[file://...]` 同时出现时，可以省略 `{联网搜索}`，系统会直接使用 UrlFetch。支持使用多个工具名并发搜索。
- 普通联网搜索和图片生成仍必须明确写 `{联网搜索}` 或 `{图片生成}`，防止普通对话误触发外部工具。
- `{联网搜索}`：默认使用 VSearch。可选工具为 `谷歌搜索`、`谷歌学术`、`Tavily`、`AnySearch`、`B站搜索`、`B站获取`；自然地说“打开网页”会自动使用 UrlFetch。
- `{图片生成}`：默认使用谷歌 NanoBanana2。可选工具为 `GPT生图`、`ZImage`、`豆包`。
- `{日用工具}`：包括主动回忆、闹钟、科学计算、女仆通讯、睡眠等待、交班续跑和 VCP 点歌台。交班必须显式写 `{日用工具}`，并用反引号指定工具名 `交班`；不要套用其他日用动作可省略目录的规则。
- `【】` 标记句子中的主要任务负载，例如搜索内容、视频地址、生图指令、回忆问题、提醒文本、数学表达式、通讯内容、睡醒提示或歌曲名。
- `[]` 标记目标、范围、数量、时间、模式、URL、Agent 名称或演出模式。
- 图片生成时，无图片 URL 表示生图；一个图片 URL 表示修图；多个图片 URL 表示多图合成。
- B站搜索可用 `[搜视频]` 或 `[搜UP主]` 指定类型；不写时默认搜索视频。`[UP主]`、`[用户]`、`[博主]`也会自动识别为搜索UP主。
- B站输入 URL、BV号或 av号时会自动获取字幕、评论和弹幕；需要截图时，在句子中加入 `[截图 30,120 秒]`。
- 打开网页时直接写“打开网页[URL]”即可；默认读取 `[文本]`，也可指定 `[截图]` 或 `[看图]`。只支持文本、截图、看图三种模式。
- 主动回忆时，`【】` 写回忆问题；可用 `[索引:名称]` 或直接 `[索引名称]` 限定记忆库，多个索引用 `|` 分隔，例如 `[小吉的地缘政治|小吉的知识]`；用 `[3条]` 指定数量。
- 搜索指定角色署名的记忆时，在 JEV 工具块外层使用 `maid:「始」角色名「末」`；搜索所有角色与其他日记知识库时，在回忆表达式中加入 `[所有知识库]`。
- 回忆日期过滤可独立写成 `[2025-04-11~2025-05-12]` 或 `[2026-02-14]`以限定日期。
- 闹钟使用 `[1分钟后]`、`[晚上10点30分]` 等时间，`【】` 写提醒内容。
- 科学计算把完整表达式原样放入 `【】`，包括积分表达式中的引号。
- 女仆通讯把目标 Agent 放入 `[]`，通讯正文放入 `【】`；可附加 `[临时通讯]`、`[异步委托]`、`[2026-10-01-14:00]` 或 `[上下文:last:3]`。
- 睡眠等待（VCPSleep）：时长放入 `[]`，醒来后的提示放入 `【】`。这是同一轮工具链内的同步等待，不是 Flowlock；不得用它等待承载当前对话的 `vcp-main` 重启。
- 交班续跑（TopicSponsor.AttachFlowlockToTopic）：通过 JEV 登记指定已有话题的 Flowlock 唤醒请求，不创建新话题、不复活旧流，也不会自行重启服务。
  - 必需：显式 `{日用工具}`、反引号包裹的 `交班`、`[真实topic_id]`、`[延时]`、`【续跑任务】`；外层 maid 使用调用者自己的署名。话题 ID 从当前会话可信上下文获取，不能用陈旧的 `current_topic_id` 猜测。
  - 延时使用一个明确的单位，例如 `[180秒]`、`[3分钟]` 或 `[1小时]`，换算后应在 1–86400 秒内；不要使用负数、复合时长或依赖静默截断。`【】` 写明先检查什么、成功后继续什么及失败时如何停止，不携带凭据。
  - 挂载成功只表示请求已登记。Agent 应简短收口，正常结束本轮；客户端认领后才开始计时，届时在指定话题发起新一轮续写。若需重启后端，必须先结束本轮并完成认领，再由已授权的独立步骤重启；不要并发调用睡眠与重启，也不要仅凭固定延时声称已保证收口。
  - 等待期间保持 VCPChat 客户端运行；此机制可用于跨后端重启，不保证跨客户端退出、重载或电脑关机。它是定时唤醒，不是服务就绪检测；醒来后先核验健康状态及任务结果，不重复执行已经完成的写操作。
  - 同一 Agent 同时只挂一个 pending 请求。失败或状态不明先核对原请求，不重复挂载；也不得借交班绕过 AICodeWorker 禁止自动轮询的规则。
  - 唤醒后心流会继续调度；任务完成时在最终正文中独占一行输出 `[[Flowlock::Complete]]`。需要人工接管或受阻时用 `[[Flowlock::Stop]]` 停止。运行时可用 Ctrl+G 或右键／中键点击 Agent 标题手动停止；无 pending 不等于心流已经停止。
  - 用法句子（仅供演示，将句子填入 JEV 字段；示例 ID 必须换成真实目标话题，不要直接执行）：
    ``请使用 {日用工具} 中的 `交班`，为话题[topic_1234567890000]设置[3分钟]后的定时唤醒，醒来后【先核验服务健康与任务状态；确认成功再继续既有授权任务，完成后停止心流。】。``
- 点歌演出模式可选：`[流光]`、`[云阶]`、`[心象]`、`[凝彩]`、`[商籁]`、`[镜台]`、`[浮名]`、`[星诞]`；不写时使用常规播放器。
